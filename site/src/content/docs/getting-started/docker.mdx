Install Wyrm using Docker compose.

## Prerequisites

- Docker
- docker-compose

## Compose

Everything you need to run Wyrm is there, including PostgreSQL itself. You can also use your own database.

<Code code={compose} lang="yaml" title="docker-compose.yaml" />

Settings can also go in `config/wyrm.toml` next to the Compose file, which is mounted at `/app/config` in the container.

Run it:

```
docker compose -f docker-compose.yaml up
```
