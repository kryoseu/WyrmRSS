Wyrm is a self-hosted RSS and Atom reader and aggregator for web and mobile,
also available as a desktop app. Want to look around first? Try the
[live demo](https://demo.wyrmrss.com).

## Choose an install method

Docker Compose and Kubernetes manifests are provided for an easy self-hosted
install. A native desktop app is also available, with no server or database
to set up. You may also build it from source.

- [Docker](/getting-started/docker/): Docker Compose setup, PostgreSQL included.
- [Desktop app](/getting-started/desktop/): macOS, Windows and Linux downloads.
- [Kubernetes](/getting-started/kubernetes/): manifests for the server and web UI.
- [Build from source](/getting-started/source/): run the server and web UI yourself.
