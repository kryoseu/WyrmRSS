The manifests below define a Deployment and Service for both `wyrm-server`
(port 3001) and `wyrm-ui` (port 3000). They're also in
[`templates/kubernetes.yaml`](https://github.com/wyrmrss/WyrmRSS/blob/main/templates/kubernetes.yaml)
on GitHub.

## Prerequisites

- A PostgreSQL database (the manifests don't include one).
- A `wyrm` namespace.
- A `wyrm-creds` secret with a `WYRM_DATABASE_CONNECTION` key holding the
  PostgreSQL connection URI.

```bash
kubectl create namespace wyrm
kubectl -n wyrm create secret generic wyrm-creds \
  --from-literal=WYRM_DATABASE_CONNECTION="postgres://wyrm:wyrm@your-db-host/wyrm"
```

## Deploy

<Code code={manifest} lang="yaml" title="kubernetes.yaml" />

kubectl apply -f kubernetes.yaml
